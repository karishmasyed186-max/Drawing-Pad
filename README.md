Drawing Pad
A simple Drawing Pad application built using Python and Tkinter. It allows users to draw on a canvas using a mouse, choose different colors, and adjust the brush size.

Features
- 🖌️ Draw using the mouse
- 🎨 Choose different pen colors
- 📏 Adjust brush size
- 🧹 Clear the drawing
- 🖥️ Simple and user-friendly graphical interface
  
Technologies Used
- Python
- Tkinter

How to Run
1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

python Drawing_pad.py

How to Use

1. Open the Drawing Pad application.
2. Use the mouse to draw on the canvas.
3. Select a color using the color selection option.
4. Change the brush size if needed.
5. Use the clear option to erase the drawing.

Project Purpose
This project was created to practice Python programming and GUI development using Tkinter.
